01 · QUICK POLL

여러분은 AI를
어디까지 사용하고 계십니까?

① 들어보기만 했다

07 · START WITH AI

시작은 코딩이 아니라
업무 설명이었습니다.

“단체 담당자가 상품과 수량을 선택하고, 일정 수량 이상이면 추가할인을 적용하고, 배송지 수집 방식까지 선택하게 해줘. 관리자는 주문과 진행상태를 확인할 수 있어야 해.”

AI 시대에는 코드를 외우는 능력보다 업무의 조건·예외·흐름을 정확하게 설명하는 능력이 중요해집니다.

08 · AI AS A TEAM

AI를 검색창이 아니라
작은 프로젝트 팀처럼

기획자

업무 흐름, 화면, 예외조건을 함께 정리합니다.

개발 보조

PHP·MySQL·HTML 코드를 만들고 수정합니다.

문제 해결

오류 화면과 코드를 바탕으로 원인을 좁힙니다.

강조: AI가 업무를 아는 것이 아니라, 업무 담당자가 AI에게 맥락을 주어야 합니다.

11 · ONE INPUT

디지털 업무의 중요한 원칙
입력은 한 번만.

❌ 다시 입력하는 구조

조합원 입력 → 직원 엑셀 입력 → 배송 담당자 재입력 → 발송용 파일 재작성

✓ 이어받는 구조

조합원 입력 → DB → 주문관리 → 배송지 → 안내 업무가 같은 데이터를 이어받음

자동화보다 먼저 중복 입력을 없애는 것부터.

12 · PROMOTION

홍보의 끝을
“발송”으로 두지 않습니다.

MESSAGE관심을 만든다
WEB바로 행동하게 한다
DATA결과를 남긴다
ACTION후속관리를 한다

“특판합니다”라는 문자에서 끝나는 것이 아니라, 상품안내 → 신청 → 상담 → 후속관리까지 연결하면 홍보가 실제 업무가 됩니다.

13 · MESSAGE AS UI

알림톡은 메시지가 아니라
업무 시작 버튼이 됩니다.

단체주문 안내

조합원 단체 추가할인 주문을 접수합니다. 상품과 수량을 확인해 주세요.

단체주문 신청하기

앱 설치 없이 메시지의 버튼 하나로 조합원을 필요한 업무 화면까지 데려갑니다.

14 · AUTOMATION

그 다음은
반복 업무를 자동화합니다.

정해진 시간

예약된 시간에 데이터 확인과 안내 작업을 실행합니다.

필요한 대상만

미제출자·미처리 건처럼 후속조치가 필요한 대상을 추립니다.

반복 최소화

Google Apps Script 등의 자동화를 이용해 사람이 매번 실행하지 않게 합니다.

사람은 예외와 판단에 집중하고,
반복은 시스템에 맡깁니다.

15 · START SMALL

다른 조합에서도
이렇게 시작할 수 있습니다.

반복업무 하나 찾기전화·문자·엑셀을 반복하는 업무
AI에게 업무 설명하기사용자, 조건, 예외, 원하는 결과를 설명
작은 웹앱 만들기처음부터 큰 시스템을 만들지 않기
직원 테스트실제 데이터 전 소수로 충분히 검증
조합원과 연결하기문자·알림톡·QR에서 웹으로 연결
다음 업무와 연결하기데이터를 재사용하며 자동화 범위 확대

17 · GUARDRAILS

빠르게 만들되,
개인정보와 검증은 더 신중하게.

필요한 개인정보만 수집
HTTPS와 관리자 접근 제한
비밀번호 암호화와 권한 구분
수정·발송 이력 관리
실제 개인정보를 AI에 그대로 입력하지 않기
운영 전 직원 테스트
중요 금융업무는 직원 최종 확인
장애 시 수동 처리·복구 방법 준비

AI는 업무 구조와 코드를 만드는 데 활용하고, 실제 개인정보는 통제된 운영환경에서 관리합니다.
